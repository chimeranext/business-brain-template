# Projects

Cada producto activo tiene su carpeta `projects/<slug>/`. Ahí viven la especificación de requisitos y la descripción de arquitectura que el cliente lee. El plan de gestión de ese mismo producto no se copia aquí: se enlaza desde [[plans/README|Plans]].

```
projects/<slug>/
├── summary.md
├── requirements/
│   ├── software-requirements-specification.md
│   ├── requirements-checklist.md
│   └── verification.md
└── architecture/
    ├── architecture-description.md
    ├── architecture-evaluation.md
    ├── decisions/
    └── views/
```
