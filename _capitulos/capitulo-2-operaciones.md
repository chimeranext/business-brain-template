# Capítulo 2: Operaciones y Cadena de Suministro

> Este capítulo sintetiza **exclusivamente** el contenido leído en los archivos `.md` extraídos de Notion (volcado del 2026-11-03) para las secciones 1.1 a 1.6. No se añade contenido fuera de lo leído.

## Objetivos

- Documentar la estructura organizativa del área de **Operaciones y Cadena de Suministro** tal como está planteada en la Plantilla de Inicio.
- Describir los subáreas que componen el área (compras, manufactura, producción, despacho, consultoría, talento humano y gestión de residuos).
- Exponer los artefactos de gestión recurrentes en cada subárea: **Retrospectivas**, **Procedimientos** y **Políticas**, junto con sus plantillas.
- Registrar los recursos y fuentes originales (verbatim) para trazabilidad.

## Conceptos clave

Se detectan, a partir de las fuentes leídas, los siguientes conceptos estructurales comunes a todas las subáreas:

- **Área 1.x — Operaciones y Cadena de Suministro**: agrupa seis dominios funcionales, cada uno con su propia página en la Plantilla de Inicio.
- **Mapeo de Proveedores**: en 1.1 Compras de Suministros se referencia una base de datos `Procuraduría` para el mapeo de proveedores.
- **Retrospectivas (DB)**: cada subárea operativa mantiene una base de datos de retrospectivas (p. ej., "Retrospectivas (Manufactura)", "Retrospectivas (Producción)", "Retrospectivas (Inventario de Ventas)", "Retrospectivas (Última Milla)", "Retrospectivas (Instalación)", "Retrospectivas (Reparaciones)", "Retrospectivas (Devoluciones)", "Retrospectivas (Consultoría 1/2/3)", "Retrospectivas (Plantilla) 1").
- **Procedimientos**: cada subárea define una subpágina "Procedimientos (…)", que contiene una plantilla "Procedimiento (Plantilla)".
- **Políticas**: cada subárea define una subpágina "Políticas (…)", que contiene una plantilla "Política (Plantilla)".
- **Minutas**: cada subárea dispone de una "Plantilla de Minuta" y, en varios casos, una "Minuta 001".
- **Plantilla de Procedimiento / Política**: estructura estándar en pasos, con `Contexto`, `Instrucciones`, `Objetivo` y `Consideraciones` por paso, acompañada de un banner de imagen.
- **Plantilla de Minuta**: estructura estándar de rendición de cuentas (ver "Procedimientos" y "Recursos" abajo).

## Procedimientos

Las plantillas de procedimiento y política son idénticas en estructura y se replican en cada subárea. Según las fuentes, el formato es:

### Procedimiento (Plantilla)
- Encabezado: "Tiempo de Lectura Aproximado: xx minutos (sin incluír videos)".
- Pasos numerados ("Paso #: Proceso XYZ"), cada uno con:
  - `Contexto`
  - `Instrucciones`
  - `Objetivo`
  - `Consideraciones`
- Cierra con un banner de imagen (`🖼 image`).

### Política (Plantilla)
- Misma estructura que el procedimiento, usando "Paso #: Política XYZ" y las mismas secciones (`Contexto`, `Instrucciones`, `Objetivo`, `Consideraciones`).
- Cierra con un banner de imagen.

### Minuta / Plantilla de Minuta
- Secciones fijas:
  - `Indicadores Clave de Rendimiento`
  - `Logros alcanzados`
  - `Desafíos y obstáculos`
  - `Metas por alcanzar`
  - `Solicitudes de Apoyo`
  - `Feedback`
  - `Feedforward`
  - `Employee Net Promoter Score` (rellenado por colaborador)
