# Capítulo 3: Tecnología e Informática

> Este capítulo sintetiza las secciones 2.1 a 2.4 del repositorio de plantillas. Todas las páginas leídas corresponden a **plantillas vacías** (estructura sin contenido poblado), por lo que el capítulo documenta el marco organizacional y la estructura de documentos que las integra, sin inventar contenido.

## Objetivos

- Documentar la estructura de documentación del área de Tecnología e Informática en sus cuatro subáreas: Aplicaciones para Usuarios Finales (2.1), Arquitectura Cloud (2.2), Administración de Informática (2.3) y Aplicaciones para Uso Interno (2.4).
- Describir el esquema común de plantillas que organiza cada subárea: retrospectivas, procedimientos, políticas y minutas.
- Establecer la estructura estándar de un procedimiento y de una política, así como el formato de minuta de reunión para el seguimiento de desempeño.

## Conceptos clave

### Subáreas del capítulo (2.x)

Cada subárea comparte la misma estructura de documentación: una base de datos de **Retrospectivas (Plantilla)**, y dos subpáginas de **Procedimientos (Plantilla)** y **Políticas (Plantilla)**, más una **Minuta 001** y la **Plantilla de Minuta**.

### Plantilla de Procedimiento

Cada procedimiento sigue una plantilla con tiempo de lectura estimado y pasos numerados. Cada paso incluye cuatro campos: Contexto, Instrucciones, Objetivo y Consideraciones.

### Plantilla de Política

Cada política sigue el mismo formato del procedimiento: tiempo de lectura estimado y pasos numerados, cada uno con Contexto, Instrucciones, Objetivo y Consideraciones.

### Plantilla de Minuta

La minuta estándar captura el desempeño y seguimiento de un colaborador o equipo mediante los siguientes campos.
