# Plans

Los planes de gestión que el cliente lee viven aquí. El plan de proyecto (ISO/IEC/IEEE 16326) y sus compañeros de riesgo (ISO/IEC/IEEE 16085) no van dentro de una unidad numerada ni en una carpeta con el nombre de una herramienta.

Nombre: `YYYY-MM-DD-plan-proyecto-<slug>.md`, y al lado el plan de gestión de riesgos y cada tratamiento escrito.
